## What this repo is

Source files for my portfolio website, hosted on GitHub Pages.

It's a static site — no build step, no framework. Just HTML, CSS and images.

## Files
├── index.html ← homepage
├── projects.html ← full project list
├── style.css ← shared stylesheet
├── resume.pdf ← CV download
├── images/ ← project thumbnails and photos
└── README.md ← this file


## Sections

- **Home** — bio, skills, three featured projects, highlights, contact
- **Projects** — full list of engineering and manufacturing work
- **Resume** — PDF download
- **Contact** — email, LinkedIn, GitHub, phone

## Development

Nothing to install. The site is plain static files — edit any `.html` or `.css` file and push to `main`. GitHub Pages rebuilds automatically within about 30 seconds.

To preview locally, just open `index.html` in a browser.
